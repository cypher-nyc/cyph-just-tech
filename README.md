# cyph-just-tech-app

The Cyph "just tech" application deck: a thirteen-slide single-page HTML/CSS/JS presentation (concept, technology, approach, feasibility, field context, public contribution) built from the `cyph-deck` shell, with `cyph-just-tech.pdf` as the exported copy. Layer: Subsidiary/site.

## Talks to

Standalone: yes. No gate, no logger, no platform service. Shared things: the `cyph-deck` shell (`styles.css`, `deck.js`, `iso3d.js`, `assets/` tree) and the one OG card at `https://cyph.city/logo/og-image.png`.

| Service | Direction | Protocol | For what |
|---|---|---|---|
| cdnjs (anime.js 3.2.2), unpkg (three 0.182.0 via importmap) | out | script tags | slide animations and the live 3D icons on the how-it-works slide |
| cyph.city (`/logo/og-image.png`) | out | hardcoded `og:image` | link preview |

Events published/subscribed: none.

## Stack

- Static HTML, CSS, vanilla JS + one ES module (`iso3d.js`, three.js); no package.json, no build.
- No port, no database, no store. Deploy target: none in this repo (no workflow, no bucket config).

## Rules for changing this repo

- Slide IDs `s0..s12` must stay contiguous (DOM order may differ: `s7` sits before `s6`); `deck.js` indexes `getElementById("s" + i)`. Adding or removing a slide is a lockstep edit of `index.html`, both HUD counters (`XX/13`), and `deck.js` (`T`, `ch`, `bars`, progress denominator, `runA` cases, lock-mode selectors).
- Dark register: `--charcoal` resolves to cream `#ede8de` on black; `underground` / `arena` / `irl` chapters use textured image backgrounds. Do not "fix" the token names.
- Design conventions from the shell: left-positioned h2 at `top:24px;left:24px`, no grey boxes, colored pills in the four route colors, crisis-style `rgba(0,0,0,0.7)` cards, `drift1`-`drift6` float keyframes, Helvetica Neue.
- `assets/videos/` holds web `.mp4` only (H.264, no audio); `.mov` masters are not kept in-repo.
- Copy is Cash-authored; only make dictated wording changes.
- Colors: Cornflower `#608FE6`, Paprika `#EC4E20`, Deep Space `#13293D`, Amaranth `#6D1A36`, Amber `#FBAF00`.
